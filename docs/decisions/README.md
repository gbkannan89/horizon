# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for Horizon.

## What is an ADR?

An ADR documents a significant architectural decision, including the context, options considered, and the rationale for the chosen approach.

## Creating an ADR

1. Copy `TEMPLATE.md` to a new file named `NNNN-title-with-dashes.md`
2. Fill in the template
3. Submit as a pull request

## ADR Template

See `TEMPLATE.md` for the required format.
